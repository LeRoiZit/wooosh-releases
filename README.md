# Wooosh - versions publiées

Ce dépôt contient uniquement les versions publiées de **Wooosh** (`Wooosh.exe`) et le fichier
`update.json` utilisé par les mises à jour automatiques. Le code source n'est pas public.

Chaque version est signée numériquement : Wooosh vérifie l'empreinte SHA-256 et la signature
avant d'installer une mise à jour.

Téléchargement : onglet **Releases**, dernière version.
